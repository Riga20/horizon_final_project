# Описание моделей

## Hubs
Хранят устойчивые бизнес-ключи и hash key.

## Links
Хранят отношения между бизнес-сущностями.

## Satellites
Хранят описательные атрибуты и техническую дату загрузки.

## Data Mart
`fct_sales_daily` имеет зерно:
**день + магазин + товар**.

`sum_sales` = сумма `amount` по товарным позициям.
`num_transactions` = количество уникальных чеков, в которых встречался товар.
`avg_transaction_amount` = средняя сумма полного чека по этим чекам.

Важно: средний чек нельзя считать как `sum_sales / num_transactions`, потому что `sum_sales` относится только к конкретному товару. Сначала рассчитывается полный чек по всем позициям, затем среднее по чекам, содержащим товар.
