# Data Governance и Data Quality

## Классификация
- Raw/Staging: технический слой, доступ ограничен ETL/аналитической роли.
- Core: корпоративные сущности и история.
- Marts: агрегированные аналитические данные.

## DQ
1. PK hub: not_null + unique.
2. Статус карты: active / blocked / expired.
3. Сумма продажи > 0.
4. Контрольная сверка raw vs mart = 0.
5. Отсутствие дубликатов hash keys.
6. Идемпотентность повторного запуска.

## Хранение
- Staging: 30 дней после успешной загрузки; при необходимости архивировать исходные файлы.
- Core: историчность атрибутов, включая SCD Type 2 для изменяемых товарных атрибутов/цен.
- Marts: хранить минимум период, необходимый для отчетности и SLA; рекомендуемо 24 месяца.
