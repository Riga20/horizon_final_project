# Глоссарий

**Средний чек** — средняя полная сумма чека по выбранной группе чеков. В `fct_sales_daily` для группы день-магазин-товар берутся только чеки, содержащие данный товар, но сумма каждого такого чека считается по всем его позициям.

**Сопоставимые продажи (LFL)** — продажи сопоставимых магазинов/объектов за сравниваемые периоды. Для корректного LFL необходимо определить набор магазинов, работавших в обоих периодах, и исключить новые/закрытые объекты согласно утвержденному бизнес-правилу.

**Инкрементальная загрузка** — загрузка только нового/изменившегося набора данных вместо полной перезагрузки.

**Data Vault** — модель DWH, разделяющая бизнес-ключи (Hub), отношения (Link) и описательные атрибуты (Satellite).

**DQ** — Data Quality, контроль полноты, уникальности, допустимых значений, согласованности и арифметической корректности данных.
