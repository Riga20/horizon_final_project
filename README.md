# Итоговая работа — ELT-пайплайн сети «Горизонт»

## Назначение
Проект реализует учебный, воспроизводимый ELT-пайплайн для розничной сети «Горизонт»:
- PostgreSQL как аналитическая БД;
- Airflow для Extract & Load;
- dbt для трансформаций;
- Data Vault для Core/DDS;
- marts для BI;
- DQ-тесты и контрольные сверки;
- идемпотентная инкрементальная загрузка.

## Важное ограничение исходного задания
В условии описаны три источника: кассовые CSV, loyalty DB и HR API/JSON. При этом для `dim_product` требуются название/категория/бренд, а для `dim_store` — адрес/регион/телефон/тип магазина; эти атрибуты в перечисленных трех источниках не описаны.
Поэтому в проекте `data/reference/products.csv` и `data/reference/stores.csv` являются **явно обозначенными демонстрационными reference-данными**, созданными только для воспроизводимости витрин. Они не выдаются за исходные данные задания.

## Структура
- `data/` — демонстрационные источники;
- `airflow/` — DAG и loader;
- `dbt/horizon/` — модели, тесты и макросы;
- `sql/` — DDL и контрольные запросы;
- `docs/` — архитектура, модель, governance, glossary, runbook;
- `dashboard/` — спецификация BI-графиков.

## Быстрый запуск
1. Запустить PostgreSQL.
2. Создать схемы и таблицы из `sql/01_init.sql`.
3. Запустить Airflow.
4. Выполнить DAG `horizon_elt_daily`.
5. В dbt выполнить:
   `dbt deps`
   `dbt build --profiles-dir .`
   `dbt docs generate --profiles-dir .`
6. Выполнить `sql/03_reconciliation.sql`.

Для учебной защиты можно показать:
- DAG;
- dbt lineage;
- результаты тестов;
- сверку 0;
- отсутствие дублей после повторного запуска;
- два BI-графика.
